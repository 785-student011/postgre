## データベース

**データベース**：大量のデータを**再利用**できるように管理する

データベース管理システム(Date Base Management System)

| ファイルシステム                                                                 | DBMS                                                                       |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| プログラム毎にファイル（拡張子の違い）が存在<br />→データの整合性が保証されない | データとプログラムが分離<br />→データの一元管理が可能<br />→整合性の保証 |
| データへの同時アクセス×                                                         | 同時アクセス〇                                                             |
| 同じ情報を含むファイルが複数存在<br />→冗長性が高い                             | データの冗長性の低さ<br />→ディスクスペースを節約                         |

- データベース管理
  　- データの入出力　DBMSの最も基本的な機能
- トランザクション管理
  - トラブルが起きたとき、トラブルが起きる前の状態に戻す
- 障害回復機能
  - バッグアップの取り方など
  - ログ書き込み：これまでのログもサーバーで管理
- 情報セキュリティ確保
  - パスワードやネットワーク接続の可否などの認証制度

###### データベースはデータの精度を保持するためのツール


### 関係データベース
##### (リレーショナルデータベース：Relational Data Basa)

表：データ管理の基本
表＝レコードの集合
| table    | table    |   車表   | メーカー表 |
| -------- | -------- | :------: | ---------- |
| レコード | レコード | メーカー | メーカーID |
| レコード | レコード |  排気量  | メーカー名 |
| レコード | レコード |    色    |
複数の表の間に関係性を見出していく

- 関係データモデルの要件
  - フラットな表構造
  - 値の一致による表の間の関連付け
  - 正規化条件を満たす
  - リレーショナル代数が用意されている
  リレーション：テーブルのこと

###### フラットな表構造
- 行：row,record テーブルの構成単位
- 列：column, field レコードの項目
- 列名：column name, field name 項目名
- 主キー：primary key, main key
  テーブル内の一つのレコードを特定するための仕組み
  ⇒NULL不可、重複不可

###### 値の一致による表の間の関連付け
ERD: Empty Relation Diagram
同じ票のなかで関連付けが行われることもある

###### 正規化条件
- 各フィールドに配列(行の繰返し)が含まれてはならない
- 各フィールドにグループ値があってはならない
⇒セル結合のようなこと×(データベースではセルとは言わない)
セル＝レコードの〇〇フィールド

正規化の段階：第1~5正規系
- 第1正規系
  - セルの結合をばらし、一行一行を独立させる
  - 繰り返し項目を別の行として独立させる
  - 他の項目から導くことができる項目は、この段階で削除しておく
- 第2正規系
  - 主キー以外の項目で、主キーの一部の項目で決まるものがあれば別の表に分割する
  - 第3正規系
    - 項目同士で依存関係にあるものを分割する

#### データ型
numeric(9,2)=整数を9桁、少数2桁を取る値
- 文字列型
  - 可変長文字列(VARCHAR バーキャラ) バーチャー：文字数が変動できる　冗長になることがある
  - 固定長文字列(CHAR キャラ、チャー)：文字数が変わらない　郵便番号、社員番号など文字数が固定されたコード体系のものに使う　指定以上の文字数になると超過分が削られる

  - 文字列連結＝||
